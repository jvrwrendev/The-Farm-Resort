# Resort Gallery & Hero Images

All images are bundled from `src/assets/images/`. Drop your resort photos into that folder using simple filenames (e.g. `1.jpg`, `2.jpg`, `hero.jpg`) and update the `import`s at the top of `src/features/landing/mockContent.ts` to match.

If you rename, keep the extension the same (`.jpg` / `.png` / `.webp`) so Vite can bundle them.

This folder (`public/`) is no longer used for resort imagery.
